访问控制

登录本管理页面用，不能为空。

客户端 Base URL 填 http://本机地址/v1

Sail 上游

可在「模型」页按模型单独覆盖。flex 只对 background=true 的 /v1/responses 生效。

「测试」按钮和批量测活使用，生成 1~8 个 token。

如 stop、seed、presence_penalty、top_k、stop_sequences，避免直接报 400。

余额

key 每次被成功使用约 15 秒后，会自动向 Sail 查询一次真实余额（不收费）。余额用完即移入报废池；之后若查到又有余额（例如账号充值），会自动恢复。

小时

0 = 关闭（推荐）。一次性额度只会减少，靠上面的自动查询就够了。

失败重试

不建议加 500/502/504：Sail 可能已开始生成，换 key 重试会重复扣费；400 是请求本身的问题，换 key 也没用。

高级：状态码规则

401 = key 无效。

多个状态码用逗号分隔，支持 5xx。
